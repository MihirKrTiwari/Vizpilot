Deploy or Run Locally

Get up and running in less than two minutes.

bash — setup & run bash
# 1. Clone & activate virtual environment
$ git clone https://github.com/MihirKrTiwari/Vizpilot.git
$ cd Vizpilot && python3 -m venv .venv && source .venv/bin/activate

# 2. Install dependencies & configure keys
$ pip install -r requirements.txt
$ cp .env.example .env # set GEMINI_API_KEY

# 3. Launch Streamlit UI or run via CLI
$ streamlit run app.py
