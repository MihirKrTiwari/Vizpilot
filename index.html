Deploy or Run Locally

Launch via Streamlit Community Cloud or clone to your machine.

bash — setup & run bash
# 1. Clone repository & initialize virtual environment
$ git clone https://github.com/MihirKrTiwari/Vizpilot.git
$ cd Vizpilot && python3 -m venv .venv && source .venv/bin/activate

# 2. Install dependencies & configure API keys
$ pip install -r requirements.txt
$ cp .env.example .env # Set GEMINI_API_KEY

# 3. Launch interactive Streamlit interface
$ streamlit run app.py
